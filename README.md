#Process Statistics Simulator

##Goal
Зрозуміти на якому рівні зараз знання із С++

##Features
Відображення таблиці із переліком процесів, сортувати їх за використанням ОЗУ, знаходити процес маючи PID, шукати процес із максимальним використанням процесора, зробити коротку статистику по процесах

##Build
C++ версії 20 і новіше

##Usage 
Для запуску скопіювати код у файл з розширенням .cpp, який підтримує відповідну версію, після запуску запускається програма у консолі із меню, яке дає можливість вибрати ту чи іншу функцію
